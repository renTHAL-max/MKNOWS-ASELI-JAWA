# Files Directory

## Jadwal PDF

Tempatkan file PDF jadwal training di folder ini dengan nama:
- `Jadwal-Public-Training-2027.pdf`

## Cara Menambahkan File:

1. Simpan file PDF Anda dengan nama `Jadwal-Public-Training-2027.pdf`
2. Copy file tersebut ke folder ini: `public/files/`
3. File akan otomatis dapat diakses di preview page

## Testing

Untuk testing tanpa file PDF yang sebenarnya, halaman preview akan menampilkan:
- Loading state
- Fallback message jika PDF tidak tersedia
- Tombol download langsung
